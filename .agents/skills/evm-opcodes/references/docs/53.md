## Stack input

0. `offset`: offset in the [memory](./about.mdx) in bytes.
1. `value`: 1-byte value to write in the [memory](./about.mdx) (the least significant byte of the 32-byte stack value).

## Examples

| * | Input 1 | * | * | Input 2 |
|--:|--------:|--:|--:|--------:|
| `1` | `0` | * | `1` | `1` |
| `2` | `0xFFFF` | * | `2` | `0xFF` |

| Memory before |
|--------------:|
| `0` |

| Memory after input 1 |
|---------------------:|
| `0xFF` |

| Memory after input 1 then 2 |
|----------------------------:|
| `0xFFFF` |

## Gas

    static_gas = {gasPrices|mstore8}
    dynamic_gas = memory_expansion_cost

The memory expansion cost explanation can be found [here](./about.mdx).

## Error cases

The state changes done by the current context are [reverted](#FD) in those cases:
- Not enough gas.
- Not enough values on the stack.

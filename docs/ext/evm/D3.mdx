## Notes

For out of bound bytes, 0s will be copied.

## Stack input

0. `mem_offset`: byte offset in the [memory](./about.mdx) where the result will be copied to.
1. `offset`: byte offset in the [data section](./about.mdx) to copy.
2. `size`: byte size to copy.

## Examples

## Gas

    minimum_word_size = (size + 31) / 32

    static_gas = {gasPrices|datacopyGas}
    dynamic_gas = {gasPrices|copy} * minimum_word_size + memory_expansion_cost

The memory expansion cost explanation can be found [here](./about.mdx).

## Error cases

The state changes done by the current context are [reverted](#FD) in those cases:
- Not enough gas.
- Execution in a legacy (non-EOF) context.

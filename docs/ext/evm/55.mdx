## Stack input

0. `key`: 32-byte key in [storage](./about.mdx).
1. `value`: 32-byte value to store.

## Examples

| * | Input 1 | * | * | Input 2 |
|--:|--------:|--:|--:|--------:|
| `1` | `0` | * | `1` | `8965` |
| `2` | `0xFFFF` | * | `2` | `0xFF` |

| Storage key before | Storage value |
|-------------------:|--------------:|
| | |

| Storage key after input 1 | Storage value |
|--------------------------:|--------------:|
| `0` | `0xFFFF` |

| Storage key after input 1 then 2 | Storage value |
|---------------------------------:|--------------:|
| `0` | `0xFFFF` |
| `8965` | `0xFF` |

## Gas

### Definitions:
- **value**: value from the stack input.
- **current_value**: current value of the storage slot.
- **original_value**: value of the storage slot before the current transaction.


    static_gas = {gasPrices|sstore}

    if value == current_value
        base_dynamic_gas = {gasPrices|warmstorageread}
    else if current_value == original_value
        if original_value == 0
            base_dynamic_gas = {gasPrices|sstoreInitGasEIP2200}
        else
            base_dynamic_gas = {gasPrices|sstoreCleanGasEIP2200}
    else
        base_dynamic_gas = {gasPrices|warmstorageread}

On top of the cost above, {gasPrices|coldsload} is added to `base_dynamic_gas` if the slot is cold. See section [access sets](./about.mdx).

## Gas refunds

    if value != current_value
        if current_value == original_value
            if original_value != 0 and value == 0
                gas_refunds += {gasPrices|sstoreClearRefundEIP2200}
        else
            if original_value != 0
                if current_value == 0
                    gas_refunds -= {gasPrices|sstoreClearRefundEIP2200}
                else if value == 0
                    gas_refunds += {gasPrices|sstoreClearRefundEIP2200}
            if value == original_value
                if original_value == 0
                    gas_refunds += {gasPrices|sstoreInitGasEIP2200} - {gasPrices|warmstorageread}
                else
                    gas_refunds += {gasPrices|sstoreReset} - {gasPrices|coldsload} - {gasPrices|warmstorageread}

See [gas refunds](./about.mdx).

## Error cases

The state changes done by the current context are [reverted](#FD) in those cases:
- Not enough gas.
- Not enough values on the stack.
- The current execution context is from a [STATICCALL](/#FA) (since Byzantium fork) or an [EXTSTATICCALL](/#FB) (since EOF fork).
- When the amount of gas left to the transaction is less than or equal 2300 (since Istanbul fork).

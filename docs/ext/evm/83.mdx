## Stack input

0. ignored value.
1. ignored value.
2. ignored value.
3. `value`: value to duplicate.

## Stack output

0. `value`: duplicated value.
1. ignored value.
2. ignored value.
3. ignored value.
4. `value`: original value.

## Example

| * | Input | Output |
|--:|------:|-------:|
| `1` | `0` | `1` |
| `2` | `0` | `0` |
| `3` | `0` | `0` |
| `4` | `1` | `0` |
| `5` | | `1` |

## Error cases

The state changes done by the current context are [reverted](#FD) in those cases:
- Not enough gas.
- Not enough values on the stack.
- Stack overflow.

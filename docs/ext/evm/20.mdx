## Stack input

0. `offset`: byte offset in the memory.
1. `size`: byte size to read in the memory.

## Stack output

0. `hash`: Keccak-256 hash of the given data in memory.

## Example

| Memory |
|-------:|
| `0xFFFFFFFF`|

| * | Input | Output |
|--:|------:|-------:|
| `1` | `0` | `0x29045A592007D0C246EF02C2223570DA9522D0CF0F73282C79A1BC8F0BB2C238` |
| `2` | `4` | |

## Gas

    minimum_word_size = (size + 31) / 32

    static_gas = {gasPrices|keccak256}
    dynamic_gas = {gasPrices|keccak256Word} * minimum_word_size + memory_expansion_cost

The memory expansion cost explanation can be found [here](./about.mdx).

## Error cases

The state changes done by the current context are [reverted](#FD) in those cases:
- Not enough gas.
- Not enough values on the stack.

## Notes

Not allowed in EOFv1 code, code containing this instruction will fail validation.

## Stack input

0. `address`: 20-byte address of the contract to query. If `address` points to an EOF contract, result is as if its code was `EF00`.

## Stack output

0. `size`: byte size of the [code](./about.mdx).

## Example

| * | Input | Output |
|--:|------:|-------:|
| `1` | `0x43a61f3f4c73ea0d444c5c1c1a8544067a86219b` | `32` |

## Gas

The static cost is {gasPrices|extcodesize}. If the accessed address is warm, the dynamic cost is {gasPrices|warmstorageread}. Otherwise the dynamic cost is {gasPrices|coldaccountaccess}. See section [access sets](./about.mdx).

## Error cases

The state changes done by the current context are [reverted](#FD) in those cases:
- Not enough gas.
- Not enough values on the stack.

# DEPRECATED: runtime-ir/jet.ll

**Status:** This handwritten LLVM IR file is DEPRECATED as of the architectural refactoring implementing ADR-001.

## What Changed

The runtime IR is now **generated programmatically** using Inkwell IR builder in the `jet_runtime` crate, specifically in the `RuntimeBuilder` module.

### Old Approach (Deprecated)
- Handwritten LLVM IR in `runtime-ir/jet.ll`
- Loaded at runtime from file
- Difficult to maintain and error-prone
- Memory layout defined in 3 places (handwritten IR, Rust structs, IR builder)

### New Approach (Current)
- Runtime IR generated by `RuntimeBuilder` in `crates/jet_runtime/src/runtime_builder.rs`
- Uses Inkwell API to construct IR programmatically
- Type-safe construction using Rust
- Memory layout unified using shared `Types` from `jet_ir` crate
- Only 2 definitions: Rust `Context` struct and generated IR (both use same type definition)

## Migration

The engine (`crates/jet/src/engine/mod.rs`) now uses:
```rust
let runtime_builder = RuntimeBuilder::new(context, "JetVM Runtime");
let module = runtime_builder.build();
```

Instead of:
```rust
let ir = MemoryBuffer::create_from_file("runtime-ir/jet.ll");
let module = context.create_module_from_ir(ir)?;
```

## Benefits

1. **Type Safety**: IR generation is checked at Rust compile-time
2. **Unified Memory Model**: Single source of truth for types in `jet_ir` crate
3. **Maintainability**: Changes to types automatically propagate to IR generation
4. **Correctness**: Fixed memory layout mismatches (pointer-based memory instead of inline array)
5. **Flexibility**: Easy to add new runtime functions programmatically
